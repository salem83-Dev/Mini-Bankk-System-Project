# Bank System

A console-based **Bank Management System** developed using **C++** as a practical project for the **Algorithms & Problem Solving – Level 3** course with **Dr. Mohammed Abu-Hadhoud**.

## About The Project

This project is designed to apply programming and problem-solving concepts through a practical banking system.

It helped me strengthen my ability to analyze problems, design solutions, organize code, and build a complete console-based application using C++.

## Features

* Add new clients
* Update client information
* Delete clients
* Search for clients
* View client list
* Deposit money
* Withdraw money
* Check account balance
* Perform banking operations
* Store and manage data using files
